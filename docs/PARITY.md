# v1 → v2 기능 보존 대장

v1.6.1(`ai-barracks-cc` 6e53aaa)에서 사용자가 할 수 있던 일을 v2에서 어떻게 하는지 추적한다. 원칙(사용자, 2026-11-08): **v1 기능은 가능한 한 모두 포함하고, 누락·부분 이식·대체를 구분하며, 제외를 임의로 완료 처리하지 않는다.** UI 이름·위치는 바뀌어도 되지만 실행 대상·보존·사용자 선택 능력은 지킨다.

- 근거: Codex 감사 `resources/reviews/20261108-aibcc-v1-parity-audit.md`(배럭), 복원 계획 council 합의(배럭 `resources/council/20261108-aibcc-v1-parity-restore/`, 합의도 85)
- 상태: **누락** · **부분 이식** · **동등 복원** · **대체 승인**(사용자) · **제외 승인**(사용자)
- 기존 self-test 통과는 회귀가 없다는 근거일 뿐, 새 항목의 완료 증거가 아니다. 완료는 아래 "자동 테스트"와 "사람 검사"로 판정한다.
- 사용자 승인이 필요한 것은 기능·데이터를 줄이는 변경뿐(새 보유 상한, ANSI 재생 제외, 이관 필드 누락, 보존 수준 저하). 내부 구조·UI 재배치는 구현 판단.
- 대체로 처리하지 않고 복원 목표로 고정: P03 새 터미널 기본 실행, P11 OFF 경로·재확인, P05 임의 다중 선택.
- 기준 후보(복원 전): `32a738a`(build 93, build-84 리뷰 수정 + 같은 commit 검증 완료).
