## 실행이 찾아낸 실제 결함 (수정 완료)

1. **⌘V가 터미널에 도달하지 않음** — SwiftUI 기본 편집 메뉴의 "붙여넣기"가 AppKit first responder(터미널)를 대상으로 인식하지 못해 비활성 상태로 단축키를 삼킴(`action=paste: enabled=false`). 실제 키보드에서도 동일. → 편집 메뉴를 first responder로 액션을 보내는 명령으로 교체.
2. **⌥⌘I 앱 단축키가 Ghostty 기본 키바인드(inspector)와 충돌** → 앱 예약 단축키를 Ghostty 설정에서 `unbind`.
3. **터미널 글꼴 폭 과대** — "SF Mono"는 이름으로 지정 불가, 한글 폰트가 1순위가 되어 셀 폭이 넓어짐 → Ghostty 기본 글꼴 + CoreText 한글 폴백.
4. **프로세스 종료 후 pane 처리** — Ghostty는 자식 종료 시 surface를 닫지 않고 SHOW_CHILD_EXITED만 보냄(래퍼 미전달). → kqueue로 종료 감지, 출력 보존 + "새 셸" 배너.
5. 산출물 목록에 SESSIONS.md(SYSTEM) 노출 → 제외.
